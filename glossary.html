Glossary

The words, in plain language

75 terms you will meet in writeups, labs, and job interviews. Each one explained like a senior would explain it to you, not like a textbook.

75 of 75 terms

AS-REP Roasting

Active Directory

An attack against accounts that do not require Kerberos pre-authentication. You request an AS-REP for the account, grab the encrypted timestamp in the response, and crack it offline to recover the password. It matters because one misconfigured account with no pre-auth is often the first foothold into a domain.

Asymmetric Encryption

Cryptography

Encryption that uses a key pair: a public key to encrypt and a private key to decrypt. It powers TLS, SSH key logins, and PGP. The tradeoff is speed, so it is usually only used to exchange a faster symmetric key.

Authentication

Career & Concepts

Proving who you are: logging in with a password, a token, or a fingerprint. It matters because almost every attack chain starts by beating authentication, through phishing, password spraying, or stolen session cookies.

Authorization

Career & Concepts

What you are allowed to do after you log in. Authentication is the door, authorization is which rooms you can enter. Most privilege escalation bugs are really authorization bugs: the app lets a low-privilege user touch something reserved for admins.

BloodHound

Active Directory

An open-source tool that maps Active Directory attack paths: users, groups, sessions, and which accounts can reach Domain Admin. Defenders use it to find and cut risky paths; attackers use it to find the shortest road to the crown jewels. Learn to read its graphs and AD suddenly makes sense.

Blue Team

Career & Concepts

The defenders: SOC analysts, incident responders, and detection engineers who protect the network. They build alerts, hunt threats, and kick intruders out. Blue team is where most junior jobs are, because every company needs people watching the screens.

Brute Force Attack

Career & Concepts

Trying every possible password or PIN until one works. It is slow but it works against weak passwords, which is why rate limiting, lockouts, and MFA exist. In CTFs and labs you will run this against login forms, hashes, and zip files constantly.

Chain of Custody

DFIR

The documented trail showing who collected, handled, and stored evidence, and when. If the chain breaks, the evidence can be thrown out of court. It is why forensics people image drives with write blockers and hash everything immediately.

Credential Stuffing

Web Security

Using leaked username and password pairs from one breach to log into other sites, counting on people reusing passwords. It is automated, cheap, and brutally effective. It is the reason unique passwords and MFA matter more than password complexity rules.

Cross-Site Request Forgery (CSRF)

Web Security

Tricking a logged-in user's browser into performing an unwanted action, like changing an email address or transferring money, by getting them to visit a malicious page. The browser sends the victim's cookies along automatically, so the site cannot tell the request was forged. Anti-CSRF tokens break the trick by requiring a secret the attacker's page cannot know.

Cross-Site Scripting (XSS)

Web Security

Injecting JavaScript into a web page that other users then load in their browsers. Stored XSS lives in the database and hits everyone who views the page; reflected XSS needs the victim to click a crafted link. It matters because a successful payload runs with the victim's session, which often means full account takeover.

CVE

Career & Concepts

A unique public ID for a known vulnerability, like CVE-2021-44228 for Log4Shell. It gives the whole industry one shared name for the same bug. When a scanner or a news post mentions a CVE, this is the identifier you look up.

CVSS

Career & Concepts

A 0 to 10 score that rates how severe a vulnerability is, based on factors like attack complexity and impact. A 9.8 means drop everything and patch; a 3.1 means schedule it. It is useful for prioritizing, but a score is not a full risk picture: exploitability in your environment matters too.

CWE

Career & Concepts

A catalog of weakness types, like CWE-79 for XSS or CWE-89 for SQL injection. Where CVE names specific bugs, CWE names the underlying mistake. Learn the top CWEs and you start recognizing bug patterns instead of isolated findings.

DCSync

Active Directory

Abusing domain replication privileges to ask a domain controller for the password hashes of any account, including the krbtgt account. It looks like a normal replica syncing, so it blends in. One DCSync and you own every credential in the domain.

DLL Injection

Reverse Engineering

Forcing a running process to load a malicious DLL so your code executes inside that process. It is used by malware to hide inside trusted programs and by analysts to hook functions and watch behavior. Seeing an unexpected DLL inside a legit process is a classic red flag.

DNS Tunneling

Network Security

Smuggling data inside DNS queries and responses, which are rarely blocked because DNS has to work. Malware uses it to exfiltrate data or receive commands when normal web traffic is filtered. It matters because it turns a protocol everyone trusts into a covert channel.

Domain Controller

Active Directory

The server that holds the Active Directory database and handles logins for the whole domain. Compromising it usually means compromising everything. Almost every AD attack, from Kerberoasting to Golden Tickets, is aimed at this box.

Dynamic Analysis

Reverse Engineering

Studying malware by running it and watching what it does: files touched, registry keys set, network connections opened. You do this in an isolated VM with snapshots, using tools like Process Monitor and Wireshark. It is faster than reading disassembly when you just need to know what the sample does.

Encryption

Cryptography

Scrambling data with a key so only someone with the key can read it. Unlike hashing, encryption is reversible. It protects data in transit (TLS) and at rest (disk encryption), and losing the key usually means losing the data.

Endpoint Detection and Response (EDR)

DFIR

Software on endpoints that watches for malicious behavior and can respond: killing processes, isolating hosts from the network. It is the blue team's eyes on every laptop and server. Attackers study which EDR is installed so they can try to blind or bypass it.

Exploit

Career & Concepts

Code or a technique that takes advantage of a vulnerability to cause unintended behavior. A vulnerability is the open window; the exploit is climbing through it. Publishing an exploit turns a theoretical bug into something anyone can use, which is why disclosure timelines matter.

File Inclusion (LFI/RFI)

Web Security

A bug where user input controls which file the server loads. Local File Inclusion reads files on the server, like /etc/passwd; Remote File Inclusion pulls code from an attacker URL and executes it. It happens when developers concatenate user input into file paths without validation.

Firewall

Network Security

A device or software that filters network traffic based on rules: block this port, allow that IP. It is the bouncer at the network's door. It matters because misconfigured rules are common, and attackers constantly probe for the ports someone forgot to close.

Golden Ticket

Active Directory

A forged Kerberos ticket-granting ticket, created with the stolen hash of the krbtgt account. It grants access to anything in the domain and can last for years if you set the lifetime. It is the ultimate AD persistence: even password changes do not kill it until the krbtgt password is reset twice.

Hashing

Cryptography

A one-way function that turns input into a fixed-length fingerprint. You cannot reverse it to get the original data back. It is used to store passwords safely, verify file integrity, and build digital signatures. Hashing is not encryption: there is no key and no decryption.

IAM (Identity and Access Management)

Cloud Security

The cloud's system for managing who can do what: users, roles, and policies. A single overly broad policy, like admin rights on a role anyone can assume, can hand over the whole account. In cloud pentests, IAM misconfiguration is the vulnerability you will exploit most often.

IDOR (Insecure Direct Object Reference)

Web Security

A bug where changing an ID in a request, like user_id=123 to user_id=124, gives you someone else's data. The app trusts the client-supplied identifier without checking ownership. It is embarrassingly common and shows up in APIs constantly, so always test it.

IMDS (Instance Metadata Service)

Cloud Security

A link-local service at 169.254.169.254 that hands cloud VMs their temporary credentials and config. If an app has SSRF, an attacker can make the server query IMDS and steal its cloud credentials. Locking down IMDS, for example requiring IMDSv2, kills a huge class of cloud attacks.

Indicator of Compromise (IOC)

DFIR

A piece of evidence that a system is compromised: a malicious IP, a bad file hash, a strange domain. IOCs are what you feed into your SIEM to find other infected machines. They go stale fast, so responders share them quickly and hunt with them immediately.

Kerberoasting

Active Directory

Requesting service tickets for accounts with Service Principal Names, then cracking the tickets offline to recover the service account's password. Service accounts often have weak, never-changed passwords and sometimes high privileges. It is quiet, needs no special access, and works depressingly often.

Kerberos

Active Directory

The authentication protocol Active Directory uses, built around tickets instead of sending passwords over the wire. You get a ticket-granting ticket at logon, then service tickets for each resource. Understanding its ticket flow is mandatory for AD work, because most AD attacks are just abusing steps of this protocol.

Lateral Movement

Network Security

Moving from one compromised machine to others inside the network: harvesting credentials, using remote admin tools, exploiting trust between systems. Getting one shell is the start; lateral movement is how it becomes a breach. Defenders fight it with network segmentation and monitoring east-west traffic.

LDAP

Active Directory

The protocol Windows uses to query Active Directory: users, groups, computers, and their attributes. Anonymous or low-privilege LDAP binds can leak the whole directory structure to an attacker. It is also how BloodHound and most AD enumeration tools gather their data.

Least Privilege

Career & Concepts

Give every user and service only the permissions they need and nothing more. It limits blast radius: a compromised account can only reach what it was allowed to touch. Most privilege escalation findings exist because someone skipped this principle.

Malware

Career & Concepts

Any software designed to harm: viruses, worms, trojans, ransomware, spyware. The name describes intent, not technique. Your job on either side is the same: understand what it does, how it got in, and how to stop it.

Memory Forensics

DFIR

Analyzing a live RAM dump to find what was happening on a machine: running processes, injected code, open connections, encryption keys. Malware often lives only in memory to avoid disk forensics, so this is how you catch it. Volatility is the standard tool you will learn first.

MITRE ATT&CK

DFIR

A public knowledge base of adversary tactics and techniques, organized as a matrix from initial access to impact. Both sides use it: red teams plan campaigns with it, blue teams map detections to it. If someone says T1486, they mean ransomware-style data encryption, and everyone knows exactly what that means.

NTLM

Active Directory

Windows' legacy authentication protocol, still everywhere despite Kerberos being preferred. It relies on password hashes, which is what makes Pass-the-Hash possible. You will see NTLM hashes in every AD lab, and cracking or relaying them is core AD tradecraft.

Obfuscation

Reverse Engineering

Deliberately making code hard to read: renamed variables, encrypted strings, junk instructions, control-flow tricks. Malware authors use it to slow analysts down; legitimate software uses it to protect intellectual property. Your job is to strip it back layer by layer until the logic shows.

OPSEC

Career & Concepts

Operational security: the discipline of not getting caught by your own trail. For a pentester it means staying in scope and not breaking production; for a red teamer it means hiding infrastructure and cleaning logs. Sloppy OPSEC burns operations and, in real engagements, can have legal consequences.

Overpass-the-Hash

Active Directory

Using a stolen NTLM hash to request a Kerberos ticket-granting ticket, giving you full Kerberos authentication as that user without knowing their password. It is the upgrade from Pass-the-Hash: instead of being limited to NTLM services, you get the whole Kerberos ecosystem. The fix is the same as ever: stop hashes from leaking in the first place.

Packer

Reverse Engineering

A program that compresses or encrypts an executable and wraps it in a small loader that restores it at runtime. Packers like UPX are used legitimately to shrink files, but malware loves them because they hide the real code from static analysis. Your first step with a packed sample is unpacking it, often just by letting it run and dumping memory.

Pass-the-Hash

Active Directory

Authenticating with a stolen NTLM password hash instead of the plaintext password. NTLM accepts the hash as proof, so cracking it is optional. Dump hashes from one box with Mimikatz or secretsdump and you can log into others as that user.

Payload

Career & Concepts

The code or commands you run after an exploit lands: a reverse shell, a credential dumper, a persistence mechanism. The exploit opens the door; the payload is what you carry through it. Choosing the right payload for the target, OS and architecture, is half the skill in exploitation.

Penetration Test

Career & Concepts

An authorized, time-boxed security test with a defined scope and a report at the end. It is not just hacking: it is hacking plus documentation, risk ratings, and remediation advice a client can act on. The OSCP and real pentest jobs live and die by report quality, not just shells.

Pivoting

Network Security

Routing your traffic through a compromised machine to reach networks you cannot see directly. The owned box becomes your stepping stone into internal subnets. Tools like chisel, ligolo, and SSH tunnels do the plumbing; pivoting is the tactic that turns one foothold into a whole network.

Privilege Escalation

Career & Concepts

Gaining higher permissions than you started with: from normal user to admin, or from admin to SYSTEM. Vertical escalation climbs the privilege ladder; horizontal escalation grabs a different account at the same level. Nearly every engagement and CTF box includes at least one privesc step.

Purple Team

Career & Concepts

Red and blue working together: attackers run their playbook while defenders watch, detect, and respond in real time. The point is to test and improve detection, not just to break in. It is the most honest security exercise a company can run.

Ransomware

Career & Concepts

Malware that encrypts a victim's files and demands payment for the key. Modern crews also steal the data first and threaten to leak it, so backups alone no longer save you. It is the most expensive common cybercrime, which is why it dominates headlines and security budgets.

Red Team

Career & Concepts

The attackers in a security exercise: they emulate real adversaries to test defenses. Unlike a pentest, a red team engagement has a goal, like stealing specific data, and nobody on the blue side knows it is happening. It tests people and process, not just technology.

Reverse Shell

Network Security

A shell where the target connects back to your machine, instead of you connecting to it. This dodges inbound firewall rules, because the connection looks like normal outbound traffic. Listeners with netcat or Metasploit catching that callback are the bread and butter of exploitation.

S3 Bucket Misconfiguration

Cloud Security

An S3 bucket left publicly readable, writable, or both, often exposing backups, keys, or customer data. It is one of the most repeated cloud mistakes in history and still shows up in breaches. The fix is boring but effective: block public access at the account level and audit bucket policies.

Salt (Cryptography)

Cryptography

Random data mixed into a password before hashing, unique per user. It stops rainbow table attacks, where precomputed hashes are matched against stolen databases. Storing unsalted password hashes in 2026 is negligence, not a mistake.

Security Information and Event Management (SIEM)

DFIR

A central platform that collects logs from across the network and fires alerts when something looks wrong. Analysts live in it during incidents, pivoting from an alert to the raw events behind it. Writing good detection rules for it is a core blue team skill.

Server-Side Request Forgery (SSRF)

Web Security

Tricking a server into making HTTP requests to somewhere it should not: internal services, cloud metadata endpoints, other customers' resources. The attacker abuses a feature like a URL fetcher or webhook to turn the server into their proxy. It is dangerous because the malicious request comes from inside the trusted network.

Server-Side Template Injection (SSTI)

Web Security

Injecting template syntax, like {{7*7}}, into a page that gets rendered server-side, which can lead to remote code execution. It happens when user input is embedded in templates without sandboxing. A quick test is injecting simple math: if the page renders 49, you have a problem.

Shellcode

Reverse Engineering

Tiny machine code, often injected into a running process, that performs one job: open a shell, download a file, pop calc. Exploit payloads are frequently shellcode because it is small enough to fit in tight buffers. Analysts learn to recognize its patterns in disassembly and memory dumps.

Silver Ticket

Active Directory

A forged Kerberos service ticket for one specific service, made with that service account's hash. Unlike a Golden Ticket, it only works against that service, but it is stealthier because it never touches the domain controller. Dump the service hash with Kerberoasting, forge the ticket, and walk in.

SMB (Server Message Block)

Network Security

The Windows file-sharing protocol, also used for remote administration and named pipes. It is ancient, chatty, and full of history: EternalBlue, PsExec, and relay attacks all ride on SMB. In AD labs you will enumerate its shares first, because misconfigured shares leak files and credentials constantly.

SOC (Security Operations Center)

Career & Concepts

The team that monitors an organization's security around the clock: triaging alerts, escalating incidents, and coordinating response. Tier 1 analysts handle the alert queue; higher tiers hunt and investigate. It is the most common entry point into cybersecurity careers.

SQL Injection (SQLi)

Web Security

Injecting SQL commands into a query the application builds from user input, letting you read, modify, or delete database contents. The classic test is a single quote in a login field. It is still near the top of every vulnerability list because string-built queries refuse to die: parameterized queries fix it completely.

Static Analysis

Reverse Engineering

Studying malware without running it: reading strings, imports, and disassembly to understand its logic. It is safe, since nothing executes, but packers and obfuscation fight you. Pair it with dynamic analysis: static tells you what the code could do, dynamic shows what it actually does.

Subnetting

Network Security

Splitting a network into smaller segments, each with its own address range. It limits broadcast traffic and, more importantly, contains breaches: one compromised subnet does not automatically mean access to the others. Know your CIDR notation cold, because every networking question assumes it.

Symmetric Encryption

Cryptography

Encryption where the same key encrypts and decrypts, like AES. It is fast, which is why it handles the bulk of real data protection. The hard part is key distribution: both sides need the same secret without anyone else seeing it, which is where asymmetric encryption helps.

TCP Three-Way Handshake

Network Security

How two machines open a TCP connection: SYN, SYN-ACK, ACK. Each side synchronizes sequence numbers so data arrives in order. You need this cold because half of network attacks and tools, from SYN scans to session hijacking, are just abusing steps of this handshake.

Threat Hunting

DFIR

Proactively searching for intruders that your alerts missed, using hypotheses like: if an attacker were here, what would they have touched. It is detection done by humans instead of rules. Good hunters know attacker behavior from frameworks like MITRE ATT&CK and look for the gaps.

TLS (Transport Layer Security)

Network Security

The protocol that encrypts traffic between your browser and a server: the S in HTTPS. It handles authentication via certificates and negotiates encryption keys. When it is misconfigured, with expired certs or weak ciphers, attackers can intercept or downgrade the connection.

TTP (Tactics, Techniques, and Procedures)

DFIR

Tactics, Techniques, and Procedures: the how of an attacker. Tactics are the goals, techniques are the methods, procedures are the exact steps. Defenders track TTPs because attacker infrastructure changes daily but their habits change slowly.

Unpacking

Reverse Engineering

Reversing a packer to recover the original executable underneath. The usual trick is letting the packed program run until it unpacks itself in memory, then dumping the process. An unpacked binary is what you actually analyze, so this step comes before everything else.

Vulnerability

Career & Concepts

A weakness in software, hardware, or process that can be exploited. Not every bug is a vulnerability: it only counts if it can actually be abused to break security properties. Finding, rating, and fixing these is the core loop of both offense and defense.

Web Application Firewall (WAF)

Web Security

A filter that sits in front of a web app and blocks malicious requests: SQL injection strings, XSS payloads, known attack patterns. It is a seatbelt, not a fix: it reduces noise and stops script kiddies, but a determined attacker can usually bypass signature-based rules. Never treat a WAF as a substitute for secure code.

WinRM (Windows Remote Management)

Network Security

Windows' native remote management protocol, running over HTTP/HTTPS on ports 5985 and 5986. With valid credentials it gives you a remote PowerShell session, which makes it a favorite for lateral movement. Evil-WinRM is the tool you will reach for in AD labs.

XML External Entity (XXE)

Web Security

Abusing an XML parser that resolves external entities, letting you read local files, scan internal ports, or in bad cases execute code. It happens when apps parse XML with external entity resolution left on. The fix is disabling external entities or switching to a safer data format like JSON.

Zero-Day

Career & Concepts

A vulnerability nobody knew about before it was exploited: no patch, no signature, no defense ready. The name comes from developers having had zero days to fix it. They are rare, expensive, and the reason defense in depth exists: you cannot patch what you do not know about.
