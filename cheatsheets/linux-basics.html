Cheat sheet

Linux Basics

The essential Linux commands for navigating the system, managing files, permissions, users, processes, and basic networking.

Navigation

pwdShow your current directory path
ls -laList all files including hidden ones
cd <dir>Move into a directory
cd ..Move up one directory level
cd ~Jump back to your home directory
find / -name "*.conf" 2>/dev/nullSearch the filesystem by filename

Files and Directories

touch file.txtCreate an empty file
mkdir -p dir/subdirCreate nested directories at once
cp -r src dstCopy files or directories recursively
mv old newMove or rename a file
rm -rf dirDelete a directory and contents
cat file.txtPrint a whole file to terminal
less file.txtScroll through a file page by page
head -n 20 file.txtShow the first 20 lines
tail -n 20 file.txtShow the last 20 lines
tail -f /var/log/auth.logFollow a log file live
grep -ri "password" /etcSearch file contents for a word
wc -l file.txtCount lines in a file

Permissions and Users

chmod 755 script.shSet owner rwx, others read and execute
chmod +x script.shMake a file executable
chown user:group fileChange file owner and group
whoamiShow your current username
idShow your user and group IDs
sudo -lList commands you can run as root
sudo su -Switch to a root shell

Processes and System

ps aux | grep sshList running processes matching ssh
topLive view of running processes
htopFriendlier interactive process viewer
kill -9 <PID>Force kill a process by ID
df -hShow disk space in readable units
free -hShow memory and swap usage
uname -aShow kernel and system info
uptimeShow how long the system runs

Networking Basics

ip aShow all network interfaces and addresses
ss -tulnList listening TCP and UDP ports
ping -c 4 8.8.8.8Send 4 ping packets to test connectivity
curl -I https://example.comFetch only HTTP response headers
