Cheat sheet

Windows and Active Directory

Commands for Windows enumeration and Active Directory recon, from PowerShell basics to domain queries.

PowerShell Essentials

Get-ChildItem -Recurse C:\UsersList files recursively under Users
Get-Process | Where-Object {$_.CPU -gt 100}Show processes using lots of CPU
Get-Service | Where-Object {$_.Status -eq 'Running'}List all running services
Test-NetConnection target.com -Port 445Test if a TCP port is open
Get-LocalUserList local user accounts
Get-LocalGroupMember AdministratorsList local admin group members
Invoke-WebRequest -Uri https://example.com/f -OutFile f.exeDownload a file with PowerShell

Local Enumeration

whoami /allShow user, groups, and privileges
net userList local user accounts
net localgroup administratorsList local administrators
net user <username> /domainShow details of a domain user
systeminfoShow OS, patches, and uptime
ipconfig /allShow full network configuration

Domain Recon

net group "Domain Admins" /domainList domain admin members
net group /domainList all groups in the domain
nltest /domain_trustsShow trusts between domains
nltest /dclist:domain.localFind domain controllers for a domain
setspn -Q */*List service principal names in AD
Get-ADUser -Filter * -Properties *Dump all domain user objects
Get-ADComputer -Filter *List all computers in the domain

Remote Access and Ticket Tools

evil-winrm -i 10.10.10.10 -u user -p 'pass'Open a WinRM shell on a target
evil-winrm -i 10.10.10.10 -u user -H <nthash>WinRM shell using a password hash
Rubeus.exe asktgt /user:user /password:pass /domain:dom.localRequest a Kerberos TGT ticket
Rubeus.exe asktgs /service:cifs/dc.dom.local /pttRequest a service ticket, inject it
Rubeus.exe kerberoastRequest crackable Kerberos service tickets
