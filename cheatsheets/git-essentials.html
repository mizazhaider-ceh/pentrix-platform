Cheat sheet

Git Essentials

The git commands students actually use daily: cloning, committing, branching, syncing, and fixing mistakes.

Getting Started

git clone https://github.com/user/repo.gitCopy a remote repo to your machine
git initStart a new repo in a folder
git statusShow changed and untracked files

Saving Changes

git add .Stage all changes for commit
git add file.txtStage one specific file
git commit -m "message"Save staged changes with a message
git commit -am "message"Stage tracked files and commit together
git diffShow unstaged changes line by line
git diff --stagedShow staged changes before committing

Syncing with Remote

git push origin mainUpload commits to the remote main branch
git pullFetch and merge remote changes
git fetchDownload remote changes without merging
git remote -vShow configured remote URLs

Branches

git branchList local branches
git checkout -b featureCreate and switch to a branch
git switch featureSwitch to an existing branch
git merge featureMerge a branch into the current one
git branch -d featureDelete a merged branch

History and Undo

git log --oneline -10Show last 10 commits, one per line
git stashShelve changes to switch context cleanly
git stash popRestore the most recent stash
git checkout -- file.txtDiscard unstaged changes in a file
git reset HEAD file.txtUnstage a file, keep its changes

Simple Conflicts

git pull origin mainPull first when push is rejected
git statusSee which files have conflicts
git mergetoolOpen a visual merge tool for conflicts
git add file.txt && git commitMark conflict resolved and commit
git merge --abortCancel the merge and start over
