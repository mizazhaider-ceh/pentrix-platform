Bash Scripting

Bash scripting building blocks: variables, conditionals, loops, functions, and one-liners you can reuse.

Variables

name="izaz"Assign a string to a variable
echo "Hello $name"Print text with variable expansion
read -p "Target: " targetPrompt and read user input
count=$((count + 1))Do arithmetic on a variable

Conditionals

if [ -f file.txt ]; then echo "exists"; fiRun code if a file exists
if [ "$a" = "$b" ]; then echo "equal"; fiCompare two strings for equality
if [ $n -gt 10 ]; then echo "big"; fiCompare numbers, greater than
[ -d dir ] && echo "is dir"Short test that a path is a directory

Loops

for i in {1..10}; do echo $i; doneLoop numbers 1 through 10
for f in *.txt; do cat "$f"; doneLoop over every txt file
while read line; do echo "$line"; done < file.txtRead a file line by line
for ip in 192.168.1.{1..254}; do ping -c1 -W1 $ip & donePing sweep a subnet in parallel

Functions

greet() { echo "Hi $1"; }Define a function taking one argument
greet izazCall a function with an argument
scan() { nmap -sV "$1"; }Wrap nmap in a reusable function
return 0Exit a function with success status

Useful One-Liners

grep -r "TODO" . --include="*.py"Find TODO comments in Python files
find . -name "*.log" -deleteDelete all log files recursively
ps aux | sort -nrk 3 | head -5Show the 5 most CPU hungry processes
history | awk '{print $2}' | sort | uniq -c | sort -nr | headRank your most used commands
tar -czf backup.tar.gz dir/Compress a directory into a tarball
chmod +x script.sh && ./script.shMake executable and run a script
