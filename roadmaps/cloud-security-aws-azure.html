Roadmap

Cloud Security (AWS + Azure)

From your first AWS console login to chaining misconfigurations into full account takeovers, across both major clouds.

Audience
Students with basic Linux and networking who want offensive cloud security skills
Difficulty
Beginner to Intermediate
Length
10-16 weeks
Steps
8 steps

The sequence

0 of 8 steps

Tick a step when you finish it. Progress is saved in this browser only.

  1. 01
    10 h

    Why this comes next: Cloud attacks exploit cloud concepts: trust policies, resource policies, regions, and the shared responsibility model. Build that mental model now, or every later technique looks like random commands.

    • AWS Cloud Practitioner Essentialscourse · Beginner · Free↗
    • Microsoft Learn: Azure Fundamentals (AZ-900) learning pathcourse · Beginner · Free↗
  2. 02
    10 h

    Why this comes next: In the cloud there is no firewall to hide behind; almost every breach starts with an overprivileged role or a misunderstood trust policy. Learn IAM before you touch any attack technique.

    • HackTricks CloudCheatsheet · Intermediate · Free↗
    • AWS Cloud Practitioner Essentialscourse · Beginner · Free↗
  3. 03
    8 h

    Why this comes next: Public S3 buckets are the classic cloud finding, and reading one bucket policy teaches you resource-based policies faster than any doc. Flaws.cloud lets you make the mistake safely, then ScoutSuite shows you how auditors spot it.

    • flaws.cloudCTF Platform · Beginner · Free↗
    • flaws2.cloudCTF Platform · Intermediate · Free↗
    • ScoutSuiteTool · Intermediate · Free↗
  4. 04
    10 h

    Why this comes next: The instance metadata service turns an ordinary SSRF into stolen IAM credentials. This one chain shows up in labs, CTFs, and real breaches, so drill it until it is muscle memory.

    • flaws.cloudCTF Platform · Beginner · Free↗
    • PortSwigger Web Security AcademyInteractive Lab · Beginner · Free↗
    • HackTricks CloudCheatsheet · Intermediate · Free↗
  5. 05
    15 h

    Why this comes next: Real cloud pentests are rarely one bug; they are small permissions chained into admin through passrole abuse, policy gaps, and trust relationships. CloudGoat gives you vulnerable AWS accounts to practice the full chain, and Pacu is the framework you run the attacks with.

    • CloudGoatTool · Intermediate · Free↗
    • PacuTool · Intermediate · Free↗
    • HackTricks CloudCheatsheet · Intermediate · Free↗
  6. 06
    12 h

    Why this comes next: Most companies run both clouds, and Azure fails differently: service principals, conditional access, and Entra roles instead of IAM policies. AzureHound maps a tenant so you can see the paths an attacker would take.

    • AzureHoundtool · Intermediate · Free↗
    • AZ-500 Microsoft Certified: Azure Security Engineer AssociateCertification · Intermediate · Paid↗
    • HackTricks CloudCheatsheet · Intermediate · Free↗
  7. 07
    10 h

    Why this comes next: Offense teaches you where the gaps are; now run the scanners enterprises actually use. Prowler and ScoutSuite show you what a clean baseline looks like, which makes the dirty ones obvious.

    • ProwlerTool · Intermediate · Free↗
    • ScoutSuiteTool · Intermediate · Free↗
    • CheckovTool · Beginner · Free↗
  8. 08
    20 h

    Why this comes next: The final skill is reading the logs: Stratus Red Team fires real attack techniques at your account so you learn what malicious looks like in CloudTrail. The AWS Security Specialty cert then proves the whole journey on a resume.

    • Stratus Red TeamTool · Intermediate · Free↗
    • AWS Certified Security - Specialty (SCS-C03)Certification · Advanced · Paid↗
    • Hacking the CloudCheatsheet · Beginner · Free↗
